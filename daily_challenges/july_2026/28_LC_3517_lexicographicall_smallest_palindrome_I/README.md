# Lexicographically Smallest Palindrome

## Problem

Given a palindromic string `s`, rearrange its characters to form the **lexicographically smallest palindrome**.

It is guaranteed that at least one palindromic rearrangement exists.

**Example**

```text
Input:
s = "bacab"

Output:
"abcba"
```

---

# Optimal Approach

## Key Observations

- A palindrome is completely determined by its **first half**.
- Every character contributes `frequency / 2` occurrences to the first half.
- If a character has an odd frequency, it becomes the middle character.
- To obtain the lexicographically smallest palindrome, build the first half in sorted order.
- The second half is simply the reverse of the first half.

## Approach

- Count the frequency of every character.
- Traverse the frequency array from `'a'` to `'z'`.
- If a character has an odd frequency, store it as the middle character.
- Append `frequency / 2` copies of every character to the first half.
- Reverse the first half to obtain the second half.
- Concatenate:
  - First Half
  - Middle Character (if any)
  - Reversed First Half

## Code

```cpp
class Solution {
public:
    string smallestPalindrome(string s) {
        vector<int> freq(26, 0);
        string half = "";
        string middle = "";

        for (char c : s) {
            freq[c - 'a']++;
        }

        for (int i = 0; i < 26; i++) {
            if (freq[i] % 2 == 1) {
                middle = i + 'a';
            }

            int cnt = freq[i] / 2;
            string p(cnt, 'a' + i);
            half += p;
        }

        string ans = half + middle;

        reverse(half.begin(), half.end());
        ans += half;

        return ans;
    }
};
```

### Complexity Analysis

**Time Complexity:** **O(N)**

**Reasoning:**
- Counting character frequencies takes **O(N)**.
- Traversing the frequency array takes **O(26)**.
- Constructing and reversing the first half together takes **O(N)**.
- Therefore, the overall complexity is **O(N)**.

**Space Complexity:** **O(N)**

**Reasoning:**
- The output string requires **O(N)** space.
- The frequency array uses **O(26)**, which is constant.

# Interview Notes

- A palindrome is uniquely determined by its first half and middle character.
- Each character contributes `frequency / 2` copies to the first half.
- At most one character can have an odd frequency in a valid palindrome.
- Constructing the first half in sorted order guarantees the lexicographically smallest palindrome.
- The second half is obtained by simply reversing the first half.
